# Antigravity Workspace Guidelines

## 📌 Mandatory Rule: Automatic README Updates

Whenever any modifications, additions, or refactors are made to the codebase:
- **Always update `readme.md` automatically** in the same response or task.
- Keep the project tree, features, setup instructions, scripts, and component inventory in `readme.md` up to date.
- Do not require the user to explicitly remind you to update the README.
